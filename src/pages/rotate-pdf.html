Frequently Asked Questions

Can I rotate a single page instead of the whole file?

Yes. Each page has its own thumbnail with Left and Right buttons, so one sideways scan in a long file can be fixed alone. The buttons at the top turn every page together, which suits a document that is entirely the wrong way round.

How do I turn a page upside down (180 degrees)?

Press the same direction button twice. Turns add up in 90-degree steps: two presses make 180, and three make 270, which equals one press the other way. The thumbnail updates, so you can check the result before saving.

Does rotating make the pages look worse?

No. The tool changes each page's rotation setting instead of redrawing the page, so text stays selectable and images keep their resolution. The file size stays close to the original.

Will the rotation still be there in other apps and when printing?

Yes. The new orientation is saved inside the PDF page, so other viewers and printers follow it. A rotate button inside a viewer is different: it is usually temporary and resets when you close the file.

Can I straighten a slightly tilted scan?

This tool only works in 90-degree steps. For any other angle, use Rotate by Custom Degrees or let Deskew PDF straighten scans automatically.

Can I rotate only the odd or even pages?

This tool has no page range field. You either rotate pages one by one with their own buttons, or all at once. To work on groups of pages, PDF Multi Tool is a better fit.

Is my PDF uploaded when I rotate it?

No. Your browser draws the thumbnails and writes the rotated file on your device, so the document stays on your computer. The download keeps the original file name.

Are bookmarks kept after rotating?

Page content, images and annotations are kept, but bookmarks are not, because the new file is built from copies of the pages. If your document depends on its outline, add it back with the Bookmark tool.
