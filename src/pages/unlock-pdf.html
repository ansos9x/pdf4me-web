Frequently Asked Questions

Can this open a PDF when I have forgotten the password?

No. You must supply the correct password; the tool does not guess or try combinations. If the file opens fine but will not let you print or copy, try Remove Restrictions instead.

Which password should I use, the one to open or the owner one?

Either works. Enter the one you have and the tool saves a copy with all encryption taken out, so no leftover restrictions stay behind.

I received a file with a password. Why remove it?

Handy when a portal or a program refuses encrypted files, when you want to merge it with other documents, or when the password is no longer needed. Only do this with files you are allowed to use.

Can I unlock several files in one go?

Yes, if they all share one password. Add them together, enter the password once, and you get decrypted-pdfs.zip with each file under its original name. Files with different passwords need separate rounds. If one file fails, the rest are still saved and the summary tells you how many failed.

Why does it say the password is wrong?

The text did not match this file. Check caps lock and stray spaces at the end, and make sure it is the password for this exact file. If the message says decryption failed, the file may be damaged, and Repair PDF might help.

Does the document change when the password is removed?

The pages, text, images, forms and bookmarks stay as they are. Only the encryption is removed, and the file keeps its name. The copy has no protection at all, so use Protect PDF if it needs a new password.

Is my file or password uploaded?

No. Removal runs in your browser with WebAssembly engines (CoherentPDF, and PyMuPDF as a backup), so the document and the password stay on your device. The engine files are fetched the first time you use the tool.

Is this the old Decrypt PDF tool?

Yes. It was renamed to Unlock PDF and behaves the same way.
