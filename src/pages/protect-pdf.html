Frequently Asked Questions

Which password do I need to fill in?

The user password is the only required field. It is the one a reader types to open the file. The owner password is optional: add a different one and the PDF also gets usage limits, so a person who opens it with the user password cannot print, copy, edit, annotate, fill in forms or reorder pages.

How is the file locked?

PDF4Me applies 256-bit AES encryption through QPDF, running as WebAssembly in your browser. There is no menu for a weaker cipher. How hard the file is to open without permission depends mostly on how long and unusual your password is.

I want to email a contract. What should I do?

Set a user password, download the locked copy and attach that one. Send the password in a separate message, for example by phone or chat, not in the same email as the file. Keep the original unlocked file for yourself.

What if I lose the password?

PDF4Me cannot get it back. The tool keeps no copy of your file or your password, and nothing here can guess it. Save the password somewhere you will find it later, and do not delete the unprotected original.

If I only type a user password, can people still print or copy?

Yes. A user password only controls opening the file. Once it is open, printing, copying and editing are allowed. To add limits, also fill in an owner password.

Can I limit printing or copying without asking for a password to open?

Not in this tool, since the user password is required here. Use Change Permissions for that: it sets the limits and leaves the file openable without a password.

How do I take the password off later?

Go to Unlock PDF, add the file, enter its password and save the new copy. You have to know the password; the tool has no way around it.

Will the recipient be able to open it?

Current readers such as Adobe Acrobat Reader, Preview, Chrome, Firefox and Edge handle AES-256 files. A very old reader built before AES-256 existed may not open it.

Does my file or password go anywhere?

No. The encryption happens on your own device inside the browser, so neither the document nor the passwords are sent to a server. The engine itself is downloaded the first time you use the tool.
