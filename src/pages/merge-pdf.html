    Add your files

    Pick the PDFs from your device or drop them onto the upload box. You can add more files later.

    2

    Set the order

    Drag each file up or down until the list matches the order you want. Type a page range for a file if you only need part of it.

    3

    Run the merge

    Press Merge PDFs. The files are joined on your device and the result is ready to save.

    Frequently Asked Questions

    Will the bookmarks survive the merge?

    Yes. Each file's bookmarks are carried into the merged document, so the outline stays usable. Page content and annotations are copied unchanged.

    Can I use only certain pages from a file?

    Yes. In File Mode, type a range like 1-3, 5 in the Pages box of a file and only those pages are used; leave it empty to take the whole file. Page Mode lays out every page as a thumbnail that you can drag into any order, even mixing pages from different files.

    How is the final order decided?

    Top to bottom, exactly as the list shows. Drag rows to rearrange them before you merge. Add More Files puts new documents at the end and keeps the order you already set.

    Why do the page numbers look odd after merging?

    The merged file is numbered 1 to N by default. If your originals use labels such as i, ii, iii or A-1 and you want to keep them, switch on Keep original page labels; files that share the same labels will then show duplicates. To print visible numbers on the pages, use Page Numbers.

    How do I keep the merged file small for an upload limit?

    Images and fonts are copied unchanged, so the merged size is close to the total of the files you add. Tick Remove duplicate fonts to keep a single copy of identical fonts. If a submission portal caps the file size, run the result through Compress PDF.

    Can I combine pages of different sizes, like an A4 form and a photo scan?

    Yes. Every page keeps its own size and rotation, so nothing is stretched or cropped. If you want one uniform size afterwards, use Fix Page Size.

    Are my files sent to a server?

    No. The merge runs inside your browser and the result is saved straight to your device, so ID scans and contracts are not uploaded.

    What about password-protected files?

    When you add a file that needs a password, the tool asks for it and then merges the unlocked pages. The merged PDF has no password; you can add one afterward with Protect PDF if needed.
