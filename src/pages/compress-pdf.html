How It Works

1

Add your PDFs

Drop one or more files onto the page, or click to choose them from your device.

2

Pick a level

Choose Low, Medium, High or Lossless. Medium is selected by default.

3

Set a size if you need one

If a portal caps uploads, enter the maximum size under Target File Size. Custom Settings has finer options such as grayscale. Then press Compress PDF.

4

Download

Download the result. If you added several files, they arrive together as a zip.

Frequently Asked Questions

Why does my PDF stay large after compressing?

Images usually make up most of a PDF. If your file has few images, or they are already small, there is little left to remove, and the result message says so when the size did not go down. You can try the High level, enter a target size, or tick Convert to grayscale in Custom Settings. For a scan that is only images, Rasterize pages is worth trying too.

What does each compression level change?

Low re-encodes images at JPEG quality 80 and scales down anything above 200 DPI. Medium uses quality 50 and 150 DPI. High uses quality 20 and 72 DPI. Lossless leaves images as they are and only tidies fonts and file structure. Medium is selected by default, and Low is the better pick if you plan to print.

Can I still select and search the text afterwards?

Yes. The text layer is left alone. Only images, fonts and file structure are reworked, so selecting, searching and clicking links still work. Rasterize pages is skipped for any document that has selectable text, unless you tick Override content protection in Custom Settings.

Does compression remove details like the author name?

No, the title and author stay in place. Embedded page thumbnails and hidden data left by editing apps are removed. A PDF/A file loses its PDF/A label unless Preserve PDF/A is ticked in Custom Settings. To clear the document details as well, use Remove Metadata.

Can I compress a scan, such as a photographed ID or a signed form?

Yes. A scanned page is one large image, which gives the tool plenty to work with. Medium or High shrinks those images in place and keeps an OCR text layer if the file has one. If the scan has no text layer, Rasterize pages in Custom Settings may reduce it further.

What can I change under Custom Settings?

They give you finer control over the compression engine. You can set image quality and maximum resolution, decide how fonts are subset and merged, flatten annotations, form fields or links, drop thumbnails and hidden data, rasterize image-only scans, keep PDF/A, and switch on Brotli. Override content protection allows signed PDFs to be compressed, which removes their signatures, and allows pages with text to be rasterized. Choosing a level resets these settings to that level's values, apart from Override content protection, Convert to grayscale, Preserve PDF/A and Brotli.

How do I fit a file under my application portal's size limit?

Type the limit into Target File Size, in KB or MB. The tool then looks for the highest image quality that still fits. If the file cannot get that small, you receive the smallest version it managed, along with a note. Ready-made pages exist for common limits, for example Compress PDF to 1MB.

Is my PDF uploaded anywhere?

No. The compression engine runs in your browser as WebAssembly, loaded together with the page, so the file stays on your computer. You can add several PDFs at once, and they come back together as compressed-pdfs.zip.
