# Interface audit: bentopdf.com vs ai4me.cfd

Audit only. No site code or content was changed and no release was published.

**Method.** Live fetches on 2026-11-11 of `www.bentopdf.com` and `ai4me.cfd` (English home, `/vi/`, `/about`, `/merge-pdf`, 404 handling, favicon and OG asset hashes), plus a read of the repo at branch `rebrand/pdf4me` (`public/`, `src/`, `index.html`, `about.html`, `public/locales`, `translations`).
Live fetches were done through a page-to-text extractor, so computed CSS and screenshots were not compared. Layout findings (D) come from source and from the bundled screenshot `public/images/bentopdf-tools.png`.
`bentopdf.com` redirects to `www.bentopdf.com`.

**Visibility scale.** High = a normal visitor sees it on first view. Medium = visible after one click or when sharing the link. Low = needs devtools, a downloaded file or a repo checkout.

**Live state observed.** ai4me.cfd serves the build-3 content: no logo strip, no compliance badges, hero present, Vietnamese title and tagline applied.

## D. Design and layout identity

All of the following is visually the same as the original (see `public/images/bentopdf-tools.png` vs ai4me.cfd source):

- **Theme:** dark gray background `#222` (`--color-gray-900: rgb(34,34,34)`) with Tailwind grays, indigo accent (`#6366f1` / `#818cf8` / `#a5b4fc`), same `src/css/styles.css` and `landing.css` (the `lp-*` component classes).
- **Hero:** two-line headline with the second line dimmed and a purple dot, an indigo rounded-square chip containing a Lucide briefcase icon, subtle grid background, three check-mark chips, one indigo pill button with an arrow.
- **Section order (home):** hero, "Why choose" stats, "Get Started with Tools" with a search bar (⌘+K shortcut and settings gear), Popular Tools, then category sections (Edit & Annotate, Convert to PDF, Convert from PDF, Organize & Manage, Optimize & Repair, Secure PDF), FAQ. We removed the logo strip, testimonials, sponsored block and compliance badges, which changes the order slightly but nothing else.
- **Tool grid:** four-column bordered cell grid with a Lucide line icon, title and two-line description, collapsible category headers.
- **Icon set:** Lucide everywhere.
- **Navbar and footer:** logo plus wordmark left, Home / About / Contact, hamburger on mobile; 5-column footer with the same headings; same language-switcher placement.
- **About page:** the same `lp-frame` / `lp-cell` stat cells and hatch/accent card styles.

**Visibility:** high (whole-site look). **Proposal:** a restyle is a design project, not a copy-edit. Start with a new logo and accent colour (for example a teal or red-leaning palette that suits the Vietnamese-first brand), a different hero composition (illustration or live demo of a file being processed), a different tool-card style (rounded cards with colour-coded categories instead of bordered cells), and a different icon set (Phosphor or Tabler). Change the section order so tools come first for Vietnamese users. Keep accessibility contrast at least as good as now.

## Notes

- **Legal context (not a finding about overlap):** the code remains a modified version of an AGPL-3.0 project. Rewriting copy, replacing assets and restyling reduce visual and textual overlap but do not change AGPL duties: keep `LICENSE` and the source-file copyright notices, and give users interacting with the site a way to get the corresponding source of your modified version. The current About-page link is the only source offer; a link in the footer as well would be safer. Some of the text copied above (FAQ, About, tool pages) is the original author's written work, so the rewrite proposals in B and C also address that.
- **Priority order proposed:** A3 logo/favicons, A1/A2 OG images, A8/A9 false or unverifiable claims, A6 version, then B (home and About rewrite), C (tool descriptions), D (restyle), E (filenames and appID), A13 repo docs.
