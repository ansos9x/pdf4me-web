About PDF4Me

PDF4Me is a set of free PDF tools for Vietnamese speakers that run in your browser: merge, split, compress, convert and edit without sending files anywhere.

Open source (AGPL-3.0)

Everyday PDF jobs, done on your own device.

Nothing to install, nothing to upload.

PDF4Me tools run inside your browser tab. Your files are not sent to our servers and we do not read them.

What you get with PDF4Me

No upload wait

Processing starts as soon as you pick a file, because nothing has to travel to a server first.

No cost, no sign-up

Use any tool without paying or registering.

Open and go

Pick a tool, choose your file, download the result. No email address needed.

Public source code

The source code is public under the AGPL-3.0 licence, so anyone can check how files are handled. It builds on open-source libraries such as PDF.js, pdf-lib, qpdf and LibreOffice.
